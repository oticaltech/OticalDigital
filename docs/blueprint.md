# **App Name**: Otical Digital

## Core Features:

- Responsive Marketing Pages: Implement the main public-facing pages (Home, Services, Work) with content areas for hero sections, service cards, project showcases, testimonials, and call-to-actions, all fully responsive and mobile-first.
- Project Portfolio Showcase: Display a grid of past projects with images, titles, and tech stacks on a dedicated work page, and highlight a selection of projects on the homepage.
- Secure Contact Form with CRM Integration: Provide a contact form for inquiries (Name, Email, Message) that stores submissions directly into a Firebase Firestore database, displaying a success message upon submission.
- Global Navigation and Footer: Develop a sticky, responsive navigation bar with links to key sections (Home, Services, Work, Contact) and a footer with company information, quick links, and social media icons.
- SEO & Performance Foundations: Ensure the site is optimized for search engines with proper meta tags and semantic headings, alongside technical optimizations like lazy loading and optimized images for fast performance.
- Interactive UI Elements: Incorporate subtle animations and micro-interactions using Framer Motion on elements like CTA buttons and navigation items to enhance the premium feel and user engagement.
- AI Project Brief Assistant: Utilize an AI tool to dynamically generate follow-up questions for prospective clients based on their initial contact message, helping them clarify their project needs and accelerate the proposal process.

## Style Guidelines:

- Background color: A deep, sophisticated violet-gray (#17141A), providing a clean canvas for a premium dark theme.
- Primary accent color: A vibrant, rich indigo-violet (#664DDB), used for key elements like headlines, interactive components, and to imbue a sense of innovation and digital elegance.
- Secondary accent color: A luminous, cool sky-blue (#84BBFC), applied for highlighting calls-to-action, active states, and creating striking gradient effects in combination with the primary color.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, tech-inspired character, ensuring strong visual impact and contemporary appeal.
- Body font: 'Inter' (sans-serif) for clean readability and a neutral, objective aesthetic, providing clear and functional text throughout the site.
- Employ a minimalist, consistent set of line-style icons from React Icons or Heroicons to maintain a clean, modern aesthetic.
- Maintain a spacious, uncluttered layout with ample negative space and consistent internal padding, following a robust grid system for all components to ensure visual harmony and a premium feel across all screen sizes.
- Implement smooth, subtle on-scroll reveal animations and tasteful micro-interactions on hover and click states, enhancing user experience without distracting from content, utilizing Framer Motion.
